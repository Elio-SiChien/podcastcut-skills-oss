# pcut：从录音到成片的播客剪辑流水线（Windows 可用）

原快照里的 skills 把每一步写成了给 AI 照做的说明书，但从录音到成片中间要靠人一步步接。`pcut` 把这条路接通了：**一条命令，从原始录音得到可以发布的成品**，中间只停一次，等你在网页上审删减。

在一期 62 分钟的三人访谈上实测（2026-11-22，Windows 10，CPU 转写）：
- 剪成 39.5 分钟（目标 40），响度 −16 LUFS，没有超过 2 秒的停顿
- 文字稿、五章时间戳、公众号图文草稿都是自动生成的
- 自动删减建议和人工通读全文后的剪法重合 76–79%，所以**审核这一步是必须的**，assemble 会拦住没审过的建议

## 它做什么

| 步 | 命令 | 做什么 | 1 小时录音大约多久 |
| --- | --- | --- | --- |
| ① | `new` | **每期都先问**：片头用哪个、剪到多少分钟、剪辑原则；再问节目名、主持人、嘉宾。上一期的回答只作参考，不会自动套用 | 1 分钟 |
| ② | `transcribe` | 先核对文件头时长和实际解码时长；faster-whisper 出词级时间戳；用 CAM++ 区分说话人（可选） | CPU 50–60 分钟；有 NVIDIA 显卡快很多 |
| ③ | `propose` | 大模型把整期切成连续的块、每块打 1–5 分，程序从低分往高分删，直到达到目标时长（5 分的块永远不删） | 1 分钟，约几毛钱 |
| ③b | `review` | 本地网页：每块可以勾留或删，能听这一段、能听删掉后的接缝，页面上实时算成品时长 | 你审的时间 |
| ④ | `assemble` | 从**原始录音**剪（用本仓库的 `cut_audio.py`）→ 长停顿压到 0.6 秒 → 加片头 → 响度标准化 → MP3；另出《删减清单》 | 2–3 分钟 |
| ⑤ | `verify` | 把成品重新转写，得到和成品对得上的文字稿；五章时间戳（必须覆盖整期，不合格会重分）；《核查报告》（时长、响度、峰值、最长静音、文件完整） | CPU 约 25 分钟 |
| ⑥ | `article` | 公众号图文草稿：3 个标题、导语、正文、时间轴；**金句逐句核对文字稿原文，对不上的直接丢掉**；嘉宾照片和链接留【】占位 | 1 分钟 |

`run` 按顺序跑完上面所有步骤，在 ③b 停下等你审；中途断了，重跑会从断的地方接着走。`status` 看现在进行到哪一步。

## 安装（Windows）

1. 装 Python 3.12（https://www.python.org/downloads/ ，勾选 Add to PATH）和 ffmpeg（`winget install Gyan.FFmpeg`）
2. 在仓库根目录运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File 安装\install_windows.ps1
   ```
   想区分说话人就加 `-Speakers`（多下载约 2 GB），并把 CAM++ 模型放到 `doctor` 提示的位置
3. 在仓库根目录建 `.env`，写一行 `PCUT_LLM_API_KEY=你的Key`。默认用 DeepSeek；换别的兼容 OpenAI 接口的模型，就再写 `PCUT_LLM_BASE_URL` 和 `PCUT_LLM_MODEL`
4. `.\pcut.bat doctor`：全部 ✅ 就可以用了

## 用

```powershell
.\pcut.bat run D:\录音\第12期.m4a D:\播客\第12期
```

成品和交付物都在 `<本期文件夹>\成品\`：成品 MP3、删减清单、文字稿、章节、核查报告、公众号图文草稿。删错了：打开 `review` 重新勾，再跑一次 `assemble` 和后面的步骤。

**名字总被识别错**：在本期文件夹放一个 `glossary.json`，例如 `{"replace": {"章三": "张三", "Open AI": "OpenAI"}}`。文字稿和图文都会按它统一。

## 为什么这样设计（都是实测踩出来的）

- **时间轴用 faster-whisper 的词级时间戳**：FunASR 的句级时间戳在 1 小时音频上漂了 25–40 秒，按它剪会剪到别的句子里
- **大模型只打分，由程序来选**：让它直接给要留的区间，目标 40 分钟它只删到 51–53 分钟，追问 3 次也不改；改成打分以后，每次都能达到目标时长
- **`cut_audio.py --no-snap`**：边界已经落在词的边上，再往静音处吸附，曾经把一句很短的话整句吞掉
- **说话人用“认声音”**：两个声音相近的人，自动聚类会把她们并成一个人；用每个人自我介绍里的一句话先建声纹，就分对了
- **显卡转写失败会自动退回 CPU**：没装 CUDA 12 的机器会报 `cublas64_12.dll` 缺失

```powershell

```
测试不需要 API Key，也不需要下载模型。包括：挑选逻辑、审核网页的保存，以及用合成音频真实走一遍 `cut_audio.py` 和 `trim_silences.py` 的剪辑。

本目录是在 MIT 许可的 `podcastcut-skills-oss` 冻结快照上新加的，原有的 skills 和脚本没有删。顺手修了两个 Windows 上的问题：`trim_silences.py` 写死的 `/tmp` 路径，以及 `cut_audio.py` 处理不到 1 分钟的音频时除以 0。
