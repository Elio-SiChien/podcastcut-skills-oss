# 反馈学习与评估（v2，不在 MVP）

> chat 服务 MVP 不做偏好自学习闭环。本文原描述的 `analyze_feedback.js` / `apply_feedback_to_rules.js` / `capture_final_feedback.js` / `用户偏好/<userId>/editing_rules/` 链已**全部移除**（属于旧 UserManager 体系，被 chat 服务下发的 `profiles/<播客名>.json` 取代）。

## 当前状态

- 审查页"导出 AI 反馈"按钮仍可用，会写 `ai_feedback_*.json`，但**没有下游消费者**。
- 评估指标脚本 `calculate_eval_metrics.js` 如果还在，仍可手动跑做 precision/recall 趋势分析，但不进自动闭环。

## v2 设计方向（参考）

要恢复"从反馈学到偏好"的闭环，**应该写回 `podcastcut-skills/profiles/<播客名>.json`**：

- 字段层：`profile.default_aggressiveness`、`profile.glossary`、`profile.tone` 可能根据反馈调整
- 入口：由 `podcastcut-onboarding-chat` skill 提供 update 命令（chat 里说"我刚才那期删多了，下次保守一点"→ aggressiveness 调档）
- 触发：每期 debrief 结束时可选 prompt "要不要把这次的删除偏好记到 profile？"

## 不再使用的旧设计（仅作历史参考）

- 两层学习（全局方法论 / 个人偏好）
- 3 个反馈捕获点（FP1/FP2/FP3）
- `用户偏好/<userId>/editing_rules/` 存储位置

旧版本可在 git history 找到（chat-mode-skills 分支之前的版本）。
